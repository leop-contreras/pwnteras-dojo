Una imagen guarda más que pixeles. Adentro también puede haber metadatos: la cámara, la fecha, el autor, comentarios...

El comando `exiftool` muestra todos los metadatos de un archivo:

```console
hacker@dojo:~$ exiftool /path/to/some/file
```

Ejecuta `exiftool` en `~/foto.png` para encontrar la flag.
